# Singu Xfriend 小星助手

安装时，星星会在安装进度页面循环浮动。软件启动后，桌面会显示小星缩略窗；点击星星或加号可以展开，拖动顶部“小星”区域可以移动窗口。

## 调用智能体

1. 在主窗口完成初始化并登录，配置模型并启动智能体。
2. 展开小星，选择智能体，输入任务并点击“发送”。回复会在小窗中逐步显示。
3. 点击“打开主窗口”可以进入同一会话，查看文件、工具执行细节或处理审批。

## 语音唤醒

语音唤醒默认关闭。输入自定义唤醒词（2–20 个字，默认“小星”），点击“开启语音唤醒”。开启时会保存唤醒词；下次启动仍需手动开启监听。

先说唤醒词，稍作停顿，再说任务。唤醒识别在 Windows 本地进行，需要安装中文语音识别组件，并允许桌面应用使用麦克风。

如果已经在主窗口的“模型设置 → 语音”中配置并选择了语音识别服务，小星会在唤醒后录制指令，停止说话约 1.2 秒后结束录音（最长 10 秒），调用该服务识别，并自动发送给所选智能体。首次使用时需要允许小窗访问麦克风。录音只在唤醒后进行，界面会提示音频将发送到语音服务。未配置识别服务时，使用 Windows 本地语音识别。

智能体正在回复时，请等待当前回复完成后再发出新的语音任务。

## 收起和关闭

- 减号收起为缩略窗，已开启的本地唤醒监听会继续。
- “关闭语音唤醒”停止麦克风监听和指令录音。
- 右上角叉号关闭助手并停止监听。在托盘设置中点击“小星助手”可以重新显示。
- 退出 Singu Xfriend 会停止本地语音进程。
